# dividend-valuation-size-based
A function reproducing the new dividend-based valuation measure for the stock market from price and total returns. 

We take the data file price-total.xlsx for size-based portfolios annual price and total returns from Kenneth French data library, 1928--2025, and apply the Python code price-total.py The blog post is here: https://my-finance.org/2026/08/01/dividend-based-valuation-measure-for-size-based-portfolios/

Update: Data file price-total-value-size.xlsx is for value-based portfolios annual price and total returns from Kenneth French data library, 1928--2025, and apply the code price-total-value-size.py The blog post is here: https://my-finance.org/2026/08/02/dividend-based-valuation-measure-for-value-based-portfolios/

Update: Code price-total-value-size-returns.py adds investigation of next year's returns vs last year's valuation measure. And this shows we might need to use stochastic volatility here as well.
